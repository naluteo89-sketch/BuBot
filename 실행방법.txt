0. 빠른 시작 (PowerShell)
cd C:\BuBot
.\.venv\Scripts\python.exe web_main.py            PC에서만 접속 → http://127.0.0.1:8000
.\.venv\Scripts\python.exe web_main.py --lan      같은 와이파이의 휴대폰에서도 접속
종료: 실행한 터미널에서 Ctrl+C
처음이라면 1번을 먼저 하세요.


1. 처음 설치 (한 번만)
1) Python 3.12 가상환경과 패키지
   cd C:\BuBot
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   (openai, numpy, pydantic)
   __pycache__ 폴더가 생기지 않도록 가상환경 전체에 설정 (가상환경을 새로 만들 때마다 한 번):
   Set-Content .\.venv\Lib\site-packages\bubot_no_pycache.pth 'import sys; sys.dont_write_bytecode = True'
   (main.py·web_main.py 외의 실행 — python -m, 자동시험, 임시 스크립트 — 에도 적용됩니다)

2) 원본 데이터 넣기
   data/ 폴더는 Git에 올리지 않습니다(.gitignore). 저장소를 새로 받았다면
   팀에서 공유한 new_prices.csv를 C:\BuBot\data\new_prices.csv 위치에 직접 넣으세요.
   이 파일이 없으면 서버·CLI·자동시험이 실행되지 않습니다.

3) API 키 (프로젝트 폴더 밖 외부 파일 방식)
   기본: C:\keydata\gpt_key.py 안의 open_Aikey 값을 읽습니다.
   폴더를 공유·백업해도 키가 포함되지 않도록 한 의도된 구성입니다. bubot/llm/gpt_api.py의 API_KEY는 비워 두세요.
   다른 경로는 환경변수 BUBOT_KEY_FILE, 또는 환경변수 OPENAI_API_KEY / BUBOT_API_KEY 사용 가능.
   우선순위: bubot/llm/gpt_api.py API_KEY → OPENAI_API_KEY → BUBOT_API_KEY → 외부 키 파일
   확인: .\.venv\Scripts\python.exe main.py check-api  (키 인식 여부만 표시, 키 값은 출력하지 않음)

4) 지식 색인 만들기 (필수, 유료 API 호출)
   .\.venv\Scripts\python.exe main.py prepare     (선택) CSV 검증·문서 생성 확인, API 미호출
   .\.venv\Scripts\python.exe main.py embed       지식 색인 임베딩
   약 450개 문서, 1회 수십만 토큰 수준(text-embedding-3-small). 결과는 storage/에 저장되며 Git에 올리지 않습니다.


2. 웹 실행
PC에서만:
  .\.venv\Scripts\python.exe web_main.py
  브라우저: http://127.0.0.1:8000
  다른 포트: .\.venv\Scripts\python.exe web_main.py --port 8001

같은 와이파이의 휴대폰·태블릿에서 (테스트용):
  .\.venv\Scripts\python.exe web_main.py --lan
  콘솔에 표시되는 "같은 와이파이 기기: http://192.168.x.x:8000" 주소를 휴대폰에서 엽니다.
  처음 실행 시 Windows 방화벽 창이 뜨면 '개인 네트워크' 허용을 선택하세요.
  --lan 은 사설 IP 주소(192.168.x.x, 10.x.x.x, 172.16~31.x.x)로 들어온 요청만 받습니다.
  도메인 이름·공인 IP·다른 사이트에서 보낸 요청은 거부합니다. 외부 공개용이 아닙니다.
  --lan 없이 실행하면 PC 자신(127.0.0.1)에서만 접속됩니다.

화면 구성:
  가격 알아보기(/)   질문 입력, '새 대화'(입력창 오른쪽 위), 예시 질문, 답변의 '계산 근거와 출처 확인'
  지난 질문(/history) 저장된 테스트 기록 열람
  데이터 안내(/data.html) 조회 가능 기간, 출처, 지역별 결측 범위
  사이드바 아래 상태: "질문할 준비가 되었어요" = API 키 인식 + 지식 색인 준비 완료
                      "일부 조회 기능을 준비 중이에요" = 키 또는 색인 확인 필요 (1-3, 1-4번)
  키 인식 표시는 인증 성공 여부가 아닙니다. 실제 호출은 질문을 보내야 확인됩니다.

참고:
  질문을 보내면 실제 GPT/임베딩 API가 호출되어 비용이 발생합니다.
  질문은 한 번에 1건씩 처리합니다. 처리 중 다른 질문을 보내면 "다른 질문을 처리 중" 안내가 나옵니다.
  조회 기간·결측 안내·출처는 /api/status가 원본 CSV에서 읽어 표시합니다 (데이터 갱신 시 HTML 수정 불필요).
  반드시 web_main.py로 띄운 주소로 접속하세요. Live Server나 python -m http.server로 web 폴더를 열면
  화면은 보이지만 사이드바가 빠지고 질문이 "BuBot 서버에 연결되지 않았어요"로 실패합니다.


3. CLI 실행 (PowerShell, C:\BuBot)
.\.venv\Scripts\python.exe main.py --help
.\.venv\Scripts\python.exe main.py check-api
.\.venv\Scripts\python.exe main.py ask "서울 2026년 8월 평균매매가격 알려줘"
.\.venv\Scripts\python.exe main.py ask "부산 최근 3개월 추이"
.\.venv\Scripts\python.exe main.py ask "강남구 요즘 흐름 어때?" --show-retrieval
.\.venv\Scripts\python.exe main.py ask "2021년에 가장 많이 오른 지역은?"
.\.venv\Scripts\python.exe main.py ask "변동률은 어떻게 계산해?"
.\.venv\Scripts\python.exe main.py search "강남구 최근 흐름"          지식 색인 검색 결과만 확인

ask 옵션: --unit (천원·만원·억원·korean), --show-analysis, --show-contexts, --show-retrieval


4. 데이터·안내 문서를 바꿨을 때
data/new_prices.csv 교체 또는 knowledge/*.md 수정 후:
  .\.venv\Scripts\python.exe main.py embed
같은 본문은 저장된 벡터를 재사용하므로 바뀐 문서만 다시 임베딩합니다.
CSV를 갱신하면 지역 프로필·시장 요약 수치가 바뀌어 해당 문서들이 다시 임베딩됩니다.
색인이 원본과 맞지 않으면 질문 처리 전에 오류로 멈추고 embed 안내를 보여 줍니다 (잘못된 색인으로 답하지 않음).


5. 자동시험
.\.venv\Scripts\python.exe -B -m unittest discover -s tests -v   (-B: __pycache__ 폴더를 만들지 않음)
실제 유료 API를 호출하지 않습니다 (가짜 임베딩·mock 사용).
data/new_prices.csv가 있어야 하며, 일부 시험(test_period_queries, test_reported_dialogue 일부)은
실제 지식 색인을 읽으므로 embed 후에 통과합니다.
시험 개수는 계속 늘고 있으므로 실행 결과 마지막 줄의 "Ran N tests"로 확인하세요.
정확도 평가(실제 API 호출·비용 발생): evaluations/accuracy_eval.py, 결과 evaluations/*.json


6. 테스트 기록
웹에서 보낸 질문마다 testlog/ 폴더에 TXT가 저장되고 전체기록.html이 갱신됩니다.
  (testlog/원본 의 JSON은 웹 뷰어용, Git에 올리지 않음)
보기: 웹 '지난 질문'(/history) 또는 C:\BuBot\testlog\전체기록.html 더블클릭
최근 100건 JSON: /api/history, 전체 JSON: /api/history/export
각 기록의 "처리 시간" 줄에 단계별 시간(질문재구성·질문분석·임베딩·검색·답변생성)이 표시됩니다.
답변 생성 실패(502) 시 오류 종류를 서버 콘솔과 기록에 남깁니다. 화면에는 상세를 보내지 않습니다.


7. 문제 해결
- 화면에 "BuBot 서버에 연결되지 않았어요 (응답 501/404)"
  → web_main.py가 아닌 다른 서버로 접속 중입니다. 8000번을 쓰는 프로그램을 끄고 web_main.py를 다시 실행하세요.
    확인: netstat -ano | findstr :8000   →  종료: taskkill /PID 번호 /F
- 휴대폰에서 접속이 안 됨
  → web_main.py --lan 으로 실행했는지, 휴대폰과 PC가 같은 와이파이인지, 방화벽에서 허용했는지 확인.
- "address already in use"
  → 8000번 포트를 다른 프로그램이 사용 중. --port 8001 로 실행하고 주소도 :8001 로 접속.
- 사이드바 상태가 "일부 조회 기능을 준비 중이에요"
  → main.py check-api 로 키 인식 확인, main.py embed 로 색인 생성.
- "답변 생성에 실패했습니다. API 설정·사용 한도·네트워크를 확인하세요."
  → 서버 콘솔의 오류 종류 확인 (키 만료, 사용 한도, 네트워크).

9. 처리 구조와 데이터 규칙 (참고)
처리 흐름
(대화 메모리) 이전 질문·답변이 있으면 GPT가 현재 질문을 단독 질문으로 재구성 → 아래 처리
질문 → 규칙 확인(광주 모호성, 보유 연도 등) → GPT 질문 분석 → 라우터
  [수치 경로] 가격 조회·비교·추이·가격 순위
    원본 CSV에서 정확한 지역·월 문서를 ID로 직접 조회 → Python 계산
    + 지식 색인 검색(지역 프로필, 같은 월 시장 요약, 관련 안내 문서)으로 보강 → GPT 답변
  [서술 경로] 흐름 요약·시장 동향·변동률 순위·용어/데이터 설명
    지식 색인 벡터 검색 → 검색된 문서만 근거로 GPT 답변
    관련 문서가 임계값 안에 없으면 GPT를 호출하지 않고 "근거 없음" 안내
답변의 '계산 근거와 출처 확인'에 계산값과 원본 행·SHA-256 출처가 표시됩니다.

지식 문서 (RAG 검색 대상, 약 450개)
knowledge/*.md          데이터 안내, 용어·계산 방법, 이용 안내 (## 제목 단위로 분할). 직접 수정·추가 가능
지역명 안내             같은 이름 지역, 권역 목록, (구) 지역 (CSV에서 자동 생성)
지역 프로필 245개       최신 가격, 1개월~10년 변화, 역대 최고·최저, 같은 시도 내 순위, 연말 가격
월별 시장 요약 176개    전국 가격, 전월/전년 동월 대비 상승·하락 상위 시군구, 시도별 변동
연도별 시장 요약 15개   전년 12월 대비 상승·하락 상위 10개 시군구 (최근 연도는 부분 연도)
지식 문서의 모든 수치는 Python이 원본 CSV에서 계산합니다. GPT가 만든 문장은 없습니다.

대화 메모리와 답변 캐시
세션마다 최근 질문·답변 3개(최소 3개)를 서버 메모리에 기억합니다. 디스크에 저장하지 않습니다.
이어지는 질문 예: "강남구 2026년 8월 가격" → "서초는?" → "그럼 1년 전이랑 비교하면?"
확인 질문 응답 예: "광주 8월 가격" → (어느 광주인지 확인) → "광주광역시"
기억은 질문 해석에만 쓰고, 답변 수치는 매번 원본·지식 색인에서 다시 가져옵니다.
이어지는 질문에는 재구성 API 호출 1회가 추가됩니다 (첫 질문은 추가 호출 없음).
서버 재시작·웹 '새 대화'·새로고침 시 기억이 초기화됩니다.
같은 질문(대화 반영 후)·데이터·색인·모델이면 처음 검증을 통과한 답을 다시 보여 줍니다 (화면에 안내 표시).
수치 확인 경고가 붙은 답은 캐시하지 않습니다. 서버 재시작 시 캐시도 초기화됩니다.

데이터 규칙
원본: data/new_prices.csv, 245개 지역, 2012-01~2026-08, 단위 천원. 결측은 0으로 계산하지 않습니다.
"최근 N개월"은 최신 월 포함 N개월 (예: 최신 8월 → 6~8월).
연도·월 없이 "요즘·현재·지금·최근"만 있으면 데이터 최신 월. 모델이 고른 과거 월은 쓰지 않습니다.
연도만 적고 월이 없을 때: "가격·평균"만 물으면 그 해 월평균 가격의 단순 평균(결측 월 제외).
  "각각·차이·비교"가 있으면 그 해 마지막 보유 월 값, 추이는 전년 12월 ~ 그 해 마지막 월.
"최근 N년 평균"은 최신 월 포함 N×12개월 (예: 최근 3년 → 2023-09~2026-08).
  변동률·하락 지역 비교는 N년 전 같은 달 기준.
"작년 대비"는 "최근 1년"(같은 달 비교). '10년'처럼 기간을 뜻하는 숫자는 연도로 보지 않습니다.
줄인 이름(강남 → 강남구)과 상위 지역 수식(포항 남구, 경기 광주)을 인식합니다.
중구·동구·광주처럼 여러 곳에 있는 이름만 적으면 후보를 보여 주고 되묻습니다.
질문에 없는 상위 지역을 모델이 덧붙이면 뺍니다. 순위의 검색 범위는 질문에 적힌 지역입니다.
가격 순위는 비교 범위 전체 유효 데이터에서 계산합니다. (구) 지역 제외.
변동률 순위는 월별·연도별 시장 요약에 미리 계산된 상위 목록으로 답합니다.
답변 속 변동률(%)을 근거와 대조해 부호가 반대이거나 근거에 없으면 1회 다시 쓰고, 그래도 다르면 [수치 확인 필요]를 붙입니다.
한/영 전환 없이 친 질문(예: tjdnf → 서울)은 한글로 바꿔 해석하고 화면에 표시합니다.
지원하지 않음: 미래 예측, 투자 추천, 전세/월세, 거래량, 개별 실거래.
