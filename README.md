# bubut
BuBot은 사용자가 자연어로 질문하면 아파트 평균 매매가격을 조회·비교하고, 계산 근거와 출처를 함께 제공하는 대화형 AI 챗봇입니다. 프로젝트의 목적은 복잡한 가격 통계표를 직접 찾아 계산해야 하는 과정을 줄이는 것입니다


10/07 — 기획 및 초기 구현
- 1차 기획서 작성 후 개발 착수
- 공공데이터 선정 및 키워드·구조화 데이터로 변환
- GPT API를 활용한 자연어 처리 구현
- 검색 조건 범위 확대 테스트

  
10/08 — 검색 개선 및 대화 기능 검증
- 단답형 챗봇 구현 및 테스트
- 테스트 로그 기반 검색 가이드 작성 및 검색 조건 수정
- 검색 결과 검토 후 공공데이터 범위 확대
- 이전 질문·검색 정보를 기억하는 연속 대화 기능 테스트
- 연속 조회 시 발생하는 검색 할당 문제에 웹 딜레이 적용 완료

  
10/12 — 답변 일관성 개선 및 호출 제어 보완 예정
- 동일 질문의 답변 불일치 원인 확인 및 수정
- 낮은 정확도·오류 응답의 대체 처리 적용
- 프로그램 공통 호출 경로에 딜레이 적용
- 웹·CLI 전체 기능 및 연속 질문 재검증

10/13 오후 — 최종 검증 및 1차 제작 마무리 예정

- 남은 오류 수정
- 차트 데이터 추가
- 실행방법과 테스트 결과 정리
- 최종 버전 저장 및 정확성·일관성 검증 결과에 따라 1차 제작 완료 판단
