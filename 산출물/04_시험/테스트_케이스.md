## 실행 기준

TC는 기존 자동시험에서 확인한 대표 케이스이며 MAN은 별도 수동시험 계획이다. TC의 실제 결과는 2026-10-12 실행 로그에서 해당 시험명이 ok인 것을 확인한 판정이다. 모든 자동시험 125건의 식별자는 `자동시험_목록.md`를 참조한다. 대표 케이스의 설명은 실제 테스트 소스의 입력과 assertion에 한정한다.

공통 사전조건: C:\BuBot, 프로젝트 가상환경, data/new_prices.csv, tests/rag_fixtures.py. 전체 실행은 `.venv/Scripts/python.exe -m unittest discover -s tests -v`이다. mock 케이스는 실제 API가 아닌 지정 응답을 이용한다. 단일 재현 시 예를 들어 `-m unittest discover -s tests -p test_period_queries.py -v`를 사용한다.
