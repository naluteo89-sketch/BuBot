# 시험 계획서

문서 ID: QA-01 / 버전: 1.0 / 기준일: 2026-10-12

## 범위와 환경

기존 tests의 unittest를 실행해 원본 파싱·계산·라우팅·대화·지식 색인·웹 응답 회귀를 확인한다. 환경은 Windows, 프로젝트 가상환경 Python, 활성 CSV 및 안내 문서이다. API 응답과 임베딩은 mock 또는 오프라인 fixture로 대체하는 기존 시험 구조를 사용한다. 일부 웹 시험은 로컬 임시 HTTP 서버를 구동한다.

## 수행 단계

1. 코드·데이터 해시 기준과 실행일을 기록한다.
2. `python -m unittest discover -s tests -v`를 실행하고 전체 로그를 보관한다.
3. 실패가 있으면 시험 이름·기대값·실제값·재현 조건을 결함표에 적는다.
4. 요구사항 추적표의 핵심 케이스와 자동시험 결과를 대조한다.
5. 별도 실 API·브라우저 수동 케이스는 실제 수행 후 결과를 기입한다.

## 판정 기준

자동시험은 실행된 assertion이 모두 통과하면 PASS이다. 실행하지 않은 케이스는 미실행, 환경 문제로 실행 불가능하면 차단으로 기록한다. 자동시험의 통과율을 자연어 정답률로 표현하지 않는다. 모델 mock 시험은 호출 경로와 근거 전달을 확인하지만 실제 모델 품질을 측정하지 않는다.

팀 제출 가능 기준은 필수 문서 구비와 최신 자동시험 결과·미실행 항목의 명시이다. 운영 배포 승인 기준은 이번 문서 범위에 포함하지 않는다.
