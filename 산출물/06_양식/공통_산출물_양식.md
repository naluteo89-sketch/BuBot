# 공통 산출물 작성 양식

문서명: / 문서 ID: / 버전: / 작성일: / 작성자: / 검토자: / 상태:

## 목적과 범위

누가 어떤 판단에 사용하는지, 포함하는 기능과 제외 범위를 2~3문장으로 작성한다.

## 요구사항 양식

| ID | 사용자 요구 | 우선순위 | 수용 기준 | 구현·설계 연결 | 상태 |
| --- | --- | --- | --- | --- | --- |
| REQ-xx | 사용자가 할 수 있는 일 | 높음·보통·낮음 | 관측 가능한 결과 | CMP / 코드 | 검토 중 |

| 클래스·파일 | 책임 | 속성과 타입 | 메서드 입력·출력 | 관계 | 예외·제약 |

## 테스트 케이스 양식

| 필드 | 작성 내용 |
| --- | --- |
| ID·요구사항 | TC-xx / REQ-xx |
| 제목·우선순위 | 무엇을 확인하는지 |
| 사전조건·데이터 | 실행 환경·원본·mock 여부 |
| 절차 | 1. 입력 2. 실행 3. 확인 |
| 기대결과 | 값·상태·화면·호출 여부 |
| 실제결과 | 실제 관측값, 실행 전에는 미실행 |
| 판정·증적 | PASS / FAIL / 차단 / 미실행, 로그 경로 |
| 실행일·실행자 | 실행 시 기입 |
