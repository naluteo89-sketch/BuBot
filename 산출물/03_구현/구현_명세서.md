문서 ID: IM-01 / 버전: 1.0 / 기준일: 2026-10-12

## 현재 구현

Python 표준 HTTP 서버와 HTML·CSS·JavaScript 화면을 사용한다. 의존 패키지는 requirements.txt의 openai>=2.0,<3, numpy>=1.26,<3, pydantic>=2,<3이다. 벡터 저장은 SQLite, 검색은 정규화 벡터의 코사인 거리이다. 특정 벡터 DB 서버를 별도로 요구하지 않는다.

실행 진입점은 main.py의 CLI와 web_main.py의 웹 서버이다. 핵심 업무는 rag_service.ask가 조정한다. 개념·정정·기간 평균 등 규칙 분기 후 일반 조회/비교/추이/순위 또는 지식 설명으로 연결한다. 질문 분석과 답변 생성은 gpt_api에 분리되어 있다.

## 실행과 갱신

프로젝트 루트에서 다음 명령을 실행한다.

```powershell
# 로컬 화면 시작
.\.venv\Scripts\python.exe web_main.py
# 문서 생성: 원본 검증 및 storage 문서 갱신
.\.venv\Scripts\python.exe main.py prepare
# 지식 색인 갱신: 실제 임베딩 API 호출 및 비용 발생 가능
.\.venv\Scripts\python.exe main.py embed
# 대화형 CLI: 실제 API 호출 가능
.\.venv\Scripts\python.exe main.py chat
# 기존 자동시험
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

웹 주소는 http://127.0.0.1:8000 이며 포트는 --port로 변경한다. 자격증명 설정값은 문서나 발표 자료에 복사하지 않는다. 이번 산출물 작업에서는 실제 색인 재구축이나 유료 API 평가를 실행하지 않았다.

2026-10-08 구조검토 자료에는 대화 기억·지식 검색·최종 수치 검사가 없다고 기록되어 있다. 현재 소스에는 ConversationMemory, knowledge_index 및 _generate의 퍼센트 검사가 존재하므로 과거 보고서의 해당 문구를 현재 상태 설명으로 재사용하지 않는다. 변경 일시·작업자·커밋은 Git 이력이 없으므로 확정할 수 없다.

## 최종 확인 중 반영된 코드 변경

2026-10-12 작업 중 확인된 최신 코드에는 다음 수정이 포함되어 있다. 이번 산출물 작성에서는 운영 코드를 직접 수정하지 않았으며 해당 최신 상태를 읽어 반영했다.

- year_query.named_region은 query_parser.find_regions를 재사용해 강남·포항 남구 같은 축약명과 모호성을 처리한다.
- 최근 N년 평균은 최신 월 포함 N×12개월을 사용한다. 예: 최근 3년은 2023-09~2026-08의 36개월이다. 변동률 비교는 N년 전 같은 달 기준을 유지한다.
- 포항 남구처럼 상위 지역 접미사를 생략한 입력을 임의 추정으로 잘못 판단하지 않도록 처리한다.
- 전국·시도 순위의 후속 질문은 이전 지역을 무조건 상속하지 않는다. 일반적인 지역 생략 후속 질문은 지역 문맥을 유지한다.
- tests/test_review_20261012.py의 5개 회귀시험이 추가되었다.
