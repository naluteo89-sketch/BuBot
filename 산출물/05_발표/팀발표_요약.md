# BuBot 팀 발표 요약

문서 ID: PR-01 / 버전: 1.0 / 기준일: 2026-10-12 / 약 5분

## 어떤 문제를 해결하나요

“서울의 월평균 매매가격은 얼마인가”, “두 지역은 얼마나 차이가 나는가” 같은 질문을 자연어로 조회합니다. 표를 직접 찾는 과정을 줄이고 계산과 원본 출처를 함께 확인할 수 있게 하는 것이 목적입니다.

## 어떻게 답하나요

질문 → 지역·기간 확인 → 원본 계산 또는 지식 검색 → 답변 → 출처 표시 순서입니다. 숫자는 Python 코드가 계산하고 모델은 제공된 근거를 바탕으로 설명합니다. 모호한 지역은 다시 묻고 데이터가 없는 기간은 안내합니다.

## 현재 구현의 핵심

| 기능 | 발표에서 설명할 내용 |
| --- | --- |
| 원본 데이터 | 245개 지역, 176개월, 2012-01~2026-08 |
| 계산 | 가격·비교·추이·순위, 기간 평균과 하락 지역 조회 |
| 설명 근거 | 안내·지역 프로필·시장 요약 454개 지식 문서 |
| 대화 | 기본 최근 3턴 기억, 세션별 분리와 새 대화 |
| 검증 | 퍼센트 불일치 시 1회 재생성, 지속 시 경고 |

## 검증 결과와 남은 일

2026-10-12 자동시험 125건이 모두 통과했습니다. 실제 모델 답변의 현재 정답률은 이번 시험으로 측정하지 않았습니다. 질문 파서의 지역 탐지는 현재 연결되어 축약명과 모호성을 처리합니다. 전체 질문 프레임 통합은 추가 검토 대상입니다.

다음 단계는 팀 요구사항 확인, 실제 API 시연 케이스 검증, 전체 질문 프레임 통합 여부 결정입니다.

## 시연 순서

1. “서울 2026년 8월 평균 매매가격”으로 값과 출처를 보여줍니다.
2. “부산은?”으로 이전 기간이 이어지는지 확인합니다.
3. “서울 2017년 평균 매매가격”으로 유효 월의 단순 평균을 설명합니다.
4. “광주 2026년 8월 가격”으로 확인 질문을 보여줍니다.

위 시나리오는 발표용 계획이며 이번 작업에서 실제 API 시연을 완료한 기록은 아닙니다. 현장 시연 전에 MAN 케이스로 결과를 남기세요.
