# 컴포넌트 설계서

문서 ID: DS-01 / 버전: 1.0 / 기준일: 2026-10-12 / 상태: 현재 구현 기술

## 전체 구조

BuBot은 숫자 조회를 원본 데이터 계산으로 처리하고, 서술형 질문에 지식 검색을 결합하는 하이브리드 RAG이다. RAG는 외부 근거를 검색하여 모델의 답변 입력에 함께 넣는 방식이다. 일부 개념·평균·정정 요청은 규칙으로 바로 답하므로 모든 답변이 외부 모델을 호출하지는 않는다.

```text
사용자
  ├─ 웹 화면 → 로컬 HTTP 서버 → 웹 서비스 ─┐
  └─ CLI ────────────────────────────────┤
                                        ↓
                          대화 메모리 → ask 라우터
                                        ├─ 규칙·기간 집계 → 원본 계산 응답
                                        ├─ 수치 조회 → CSV 원본 계산 + 관련 지식
                                        └─ 설명 질문 → 지식 벡터 검색
                                                      ↓
                                            모델 답변 → 변동률 검사
                                                      ↓
                                            코드 출처 표시 → 결과

CSV + 안내 Markdown → 지식 문서 생성 → 임베딩 → SQLite 지식 색인
웹 처리 결과 → 테스트 기록 JSON / TXT / HTML
```

## 정상 흐름과 예외

웹 요청은 형식·크기·Host/Origin을 검사한 뒤 웹 서비스가 질문·단위·세션을 검증한다. 대화 모듈은 이전 요약을 전달하고 ask가 규칙 처리 또는 모델 경로를 선택한다. 일반 모델 경로는 색인 정합성을 먼저 확인한다. 결과에는 답변, facts, sources, 대화 사용량, timings가 포함된다. 웹 서버는 기록 저장 결과와 전체 시간을 추가한다.

색인 누락·불일치는 재구축 안내 대상이다. 지식 검색 결과가 없으면 근거 없음 안내로 종료한다. 답변의 퍼센트 값 불일치는 1회 재생성 후 경고할 수 있다. 이 검사는 모든 문장이나 모든 가격의 사실 검증이 아니다. 외부 API 예외는 웹에서 502, 입력 오류는 400, 처리 중 추가 질문은 429로 응답한다.

## 경계와 저장소

`data/new_prices.csv`는 활성 원본이며 `data/data.csv`를 현재 조회 원본으로 간주하지 않는다. 가격 문서는 43,365개, 지식 문서는 454개이다. 지식 종류는 guide 18, region_profile 245, market_monthly 176, market_annual 15이다. 현재 답변용 지식 색인과 과거의 가격 문서 벡터 색인을 구분해야 한다.

`storage/knowledge_index.json`은 색인 식별 정보, `storage/vectors/vectors.sqlite3`는 지식 문서와 벡터 저장소이다. 대화 문맥은 프로세스 메모리에만 존재한다. 별도 테스트 기록은 디스크에 남으므로 새 대화나 서버 재시작이 저장 기록까지 삭제하지는 않는다.

`query_parser.find_regions`는 year_query.named_region에서 호출되어 지역명 축약·상위 지역 수식·모호성 판정에 사용된다. Mention은 이 경로에서 사용된다. Period·QueryFrame 및 parse_question 전체 라우팅은 현재 운영 호출이 확인되지 않아 부분 연결로 구분한다.
