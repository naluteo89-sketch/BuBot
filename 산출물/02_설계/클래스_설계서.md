# 클래스 설계서

문서 ID: DS-02 / 버전: 1.0 / 기준일: 2026-10-12 / 상태: 현재 소스 기준

## 설계 방식

BuBot은 함수 중심 모듈과 데이터 클래스가 함께 구성된 프로젝트다. 실제 존재하지 않는 Service·Repository 클래스를 가정하지 않는다. 함수 단위 책임은 컴포넌트 설계서에, 실제 클래스 속성·메서드·행 번호는 `클래스_자동목록.md`에 연결한다.

| 클래스 | 핵심 속성 | 주요 동작 | 책임·제약 |
| --- | --- | --- | --- |
| Document | id, text, metadata | dataclass 생성 | 불변 데이터 객체. 월·지역·원본 행·해시 등 근거를 보유 |
| Corpus | documents, source_hash, region_count, months, missing_count | dataclass 생성 | 검증된 가격 문서 묶음. Document 여러 개 포함 |
| KnowledgeCorpus | documents, source_hash, csv_hash, latest_month | dataclass 생성 | CSV와 안내문 기반 지식 문서 묶음 |
| ConversationMemory | turns, ttl, max_sessions, clock, _sessions, _lock | check, history, add, reset, size, _expire | 세션 검사·최근 턴 관리. OrderedDict·deque·RLock 사용 |
| VectorClient | path 등 생성자 필드 | connect, cached_vectors, cache_vectors | SQLite 연결 및 임베딩 캐시 |
| VectorCollection | client, name 등 생성자 필드 | count, get, upsert, _rows, query | 컬렉션 조회·저장·정규화 벡터 검색 |
| Analysis | intent, region_names, month, start_month, end_month, display_unit, level, rewritten_query, message | Pydantic 검증 | 추가 필드 금지, strict=True, 월 YYYY-MM 형식 |
| Condensed | is_followup, standalone_question | Pydantic 검증 | 후속 질문 여부와 독립 질문 |
| Handler | BaseHTTPRequestHandler 상속 | send, trusted, do_GET, do_POST, log_message | 로컬 HTTP 요청과 응답 처리 |
| Period | kind, month, start, end, year, notes, spans | explicit | 별도 파서 기간 모델. 현재 주 실행 경로 미연결 |
| Mention | text, span, candidates, exact, qualifier | dataclass 생성 | find_regions가 반환하는 지역 표현 후보. named_region에서 사용 |
| QueryFrame | text, targets, ambiguous, scope, level, enumerate, period, cues, intent, threshold, top_n | dataclass 생성 | 별도 파서의 질문 프레임. 전체 라우터 연결은 미확인 |

## 관계

```text
Corpus ── 포함 ──> Document 목록
KnowledgeCorpus ── 포함 ──> Document 목록
VectorCollection ── 참조 ──> VectorClient ── 연결 ──> SQLite
Handler ── 함수 호출 ──> web.service ──> conversation.chat
conversation.chat ── 사용 ──> ConversationMemory
gpt_api ── 응답 검증 ──> Analysis / Condensed
QueryFrame ── 포함 ──> Period  [현재 미연결 파서]
```

## 핵심 메서드 계약

| 메서드 | 입력 | 출력·변경 | 예외와 경계 |
| --- | --- | --- | --- |
| ConversationMemory.check | 세션 문자열 | 검증한 문자열 | 영숫자·밑줄·하이픈 8~64자 이외 ValueError |
| ConversationMemory.history | session_id | 저장 요약의 목록 사본 | 만료 세션 정리 후 반환 |
| ConversationMemory.add | session_id, turn | 최근 turns개 유지 | 용량 초과 시 오래된 세션 제거 |
| ConversationMemory.reset | session_id | 해당 세션 제거 | 다른 세션과 저장 기록은 유지 |
| VectorCollection.upsert | ids, documents, metadatas, embeddings | SQLite 저장 및 캐시 갱신 | 임베딩 차원은 색인 생성 및 벡터 처리 경로에서 검증 |
| VectorCollection.query | query_embeddings, n_results, include, where | ids·거리·문서·metadata | where에 맞는 후보의 코사인 거리 순 |
| Handler.do_POST | HTTP 요청 | JSON 및 HTTP 상태 | 형식·크기·동시 요청·외부 호출 오류 구분 |

Analysis.intent는 lookup·trend·compare·argmax·argmin·explain·clarify로 제한된다. 규칙 경로의 concept·period_decline 같은 내부 intent는 별도의 결과 dict에 들어가므로 이 스키마의 허용값을 모든 내부 경로에 적용하지 않는다.
