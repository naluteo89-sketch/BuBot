# BuBot 산출물 안내

부동산 평균 매매가 조회 AI 개발의 분석·설계·구현·시험 자료입니다. 팀 내부 약식 발표와 코드 변경 후 문서 유지보수를 목적으로 합니다. 현재 구현을 역으로 정리한 요구사항 초안이며, 회사의 승인된 요구사항을 대체하지 않습니다.

| 항목 | 내용 |
| --- | --- |
| 기준일 | 2026-10-12, Asia/Seoul |
| 문서 버전 | 1.0 |
| 작성 | 코드 분석 기반 초안 |
| 검토자와 승인 | 팀 검토 시 기입 / 미승인 |
| 코드 기준 | Git 이력 없음. 파일 SHA-256으로 기준 기록 |

## 읽는 순서

1. `05_발표/팀발표_요약.md`: 5분 발표용 핵심 내용
2. `01_기획/프로젝트_기획서.md`: 추진 배경·목표·범위·구조·일정 (2026-10-08 기준)
3. `01_분석/사용자_요구사항_정의서.md`: 사용자 관점과 수용 기준
4. `02_설계/컴포넌트_설계서.md`, `클래스_설계서.md`: 구성과 책임
5. `03_구현/구현_명세서.md`: 현재 구현과 주요 설정
6. `04_시험/테스트_케이스.md`, `시험_결과서.md`: 시험 절차와 실행 결과

`발표용_통합본.html`을 브라우저로 열면 모든 문서를 목차와 함께 볼 수 있습니다. 검색과 인쇄를 지원하며 외부 통신 없이 열립니다. 문서는 Markdown 원본을 수정한 뒤 열람본을 다시 생성합니다. HTML을 직접 편집하면 재생성 시 사라집니다.

## 공개 양식 적용

[Atlassian 공개 요구사항 양식](https://www.atlassian.com/software/confluence/templates/product-requirements)의 목적·범위·요구사항·열린 질문 구성을 참고했습니다. [TestRail 공개 테스트 케이스 양식](https://support.testrail.com/hc/en-us/articles/14927678348052-Test-case-templates)의 사전조건·절차·기대결과 구성을 적용했습니다. 확인일은 2026-10-12입니다. 양식의 항목 구성을 참고해 한국어 약식 문서로 새로 작성했으며 공식 양식 준수 인증을 의미하지 않습니다. 회사 비공개 양식이나 소스코드를 외부 사이트에 업로드하지 않았습니다.

## 수정과 재생성

프로젝트 루트 `C:\BuBot`에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe 산출물\도구\refresh.py
```

이 명령은 파일 기준표·코드 목록·자동시험 목록·통합 HTML만 갱신합니다. 직접 작성한 요구사항·설계 설명·시험 결과 판정은 덮어쓰지 않습니다. Python과 markdown-it-py가 필요하며 현재 가상환경에서 확인했습니다.

코드가 바뀌면 `유지보수_가이드.md`에 따라 관련 문서와 시험 결과도 함께 수정하세요. 자동 생성 자료가 최신이어도 요구사항이나 수동 문서가 자동으로 검증되는 것은 아닙니다.
