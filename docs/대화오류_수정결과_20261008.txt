대화 오류 수정 결과

1. 기간 평균: 월평균 가격을 Decimal로 합산하고 유효 월 수로 나눕니다.
연말 한 달 가격을 연평균으로 사용하지 않습니다. 결측은 0으로 취급하지 않습니다.
서울 2017년: 581827.75천원 = 5억 8,182만 7,750원 (12개월)
서울 2025년: 1207375.583333...천원 = 12억 737만 5,583원 (12개월, 원 단위 반올림)
이는 월평균 가격의 단순 평균이며 거래 건수 가중 평균이 아닙니다.

2. 음수 변동률 지역: 최신 월 2026-08 기준 4년 전 2022-08과 비교.
원본 시군구 항목 중 183개 비교 가능, 117개 하락, 결측/시작값 0인 13개 제외.
시와 하위 구는 CSV의 별도 항목으로 포함될 수 있으며, 서로 겹치지 않는 행정구역 개수라는 뜻은 아닙니다.
개념 설명 규칙은 지역 검색 요청에 적용하지 않습니다.

3. 후속 질문: 하락 지역 목록은 원래 조회를 다시 계산하며 6개 요약만으로 전체를 판단하지 않습니다.
정정 질문의 누락 지역과 연도는 최근 확정된 조건에서 복원합니다.

4. 데이터 없음 응답: 연도 자료 유무는 원본 월 목록으로 확인합니다.
사용자의 오류 지적에는 원본을 재조회하며 수집 지연 등의 원인을 추측하지 않습니다.

5. 출처: 모델 답변 본문의 출처 안내/자리표시자는 제거하고 코드가 만든 출처를 별도 상세에 유지합니다.

검증: 원본 CSV 독립 계산 테스트 및 사용자 로그 기반 10턴 재검증.
실제 대화 재구성 API가 필요한 턴은 API를 호출했고, 집계는 원본 코드 계산으로 확인했습니다.
첫 재검증 중 설명 질문 오류를 추가 발견해 보완했으며 실패 기록도 보존합니다.
최종 기록: evaluations/dialogue_period_fix_final.json
이 검증은 해당 회귀 사례의 개선 확인이며 모든 자연어 질문의 정확도를 보장하지 않습니다.

주요 파일
bubot/period_queries.py: 기간 해석, 평균, 하락 지역, 개념·정정 처리
bubot/rag_service.py: 공통 계산 경로 연결, 후속 질문 조건 유지, 부재 응답 검증
bubot/source_display.py: 표시 출처 분리
